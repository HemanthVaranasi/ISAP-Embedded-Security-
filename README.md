# 🔐 SIMD-Optimized ISAP Algorithm for Embedded Security

## 📌 Overview
This project implements lightweight cryptographic algorithms (ISAP, ASCON) optimized for embedded systems like Arduino Uno and ESP32.
Designed specifically for secure communication in resource-constrained IoT environments.

## 🚀 Key Features
- SIMD-optimized ISAP implementation
- Lightweight authenticated encryption
- Performance benchmarking (execution time, memory, throughput)
- Optimized for resource-constrained devices

## 🛠️ Technologies Used
- Embedded C/C++
- Arduino Uno
- ESP32

## 🔐 Security Focus
- Confidentiality
- Integrity
- Authentication

## 📊 Results
- Reduced computation time
- Improved efficiency with optimized permutation rounds

## ▶️ How to Run
1. Open project in Arduino IDE
2. Upload to ESP32 / Arduino Uno
3. Monitor output via Serial Monitor

## 📁 Project Structure
- Arduino implementations
- ESP32 implementations
- WSL-based testing files
